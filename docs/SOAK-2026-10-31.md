# Engine soak, 2026-10-31

Long-run fuzz soak of the shared engine, run unattended on the owner's Mac
(10 cores). Engine tip under test: `private/v4/mac` at 5e08852 (newer than
ecbd547). No engine code was changed; this file is the only change on the branch.

Status: IN PROGRESS (started 18:41 local). This file is updated as steps finish.

## Setup

- `mac/Tools/fuzz-check.sh` built `mac/build/fuzz_edit` (clang++ -O1, ASan + UBSan,
  `-fno-sanitize-recover=undefined`); a 2-seed x 100-op run passed.
- `fuzz_load` came from the headless CMake project
  (`cmake -S mac/Tools/headless -B build/headless -DCL_SANITIZE=ON`), also ASan + UBSan.
- Parallelism 8 for everything. Per-seed cap 15 minutes (900 s) for the fuzz_edit sweeps.
- Per-seed driver: a small wrapper that loads `mac/Tools/fuzz-sweep.py`'s own
  `first_line` and uses its exact status rules (exit 0 = passed; exit 1 without a
  sanitizer report = failed; any other exit or a sanitizer report = crashed; over the
  cap = unfinished). It differs from `fuzz-sweep.py` in only two ways: each seed's
  result is appended to a file as soon as it ends, and each seed gets its own
  `CL_FUZZ_DUMP` directory so a failing seed's kept circuits are not overwritten.
- "Ops count wide": CORE-HARDENING.md does not name one number. Its wide-fixtures
  row ran at 500 ops (and once 1000); CI uses 300. This soak used **500** for
  steps 2 and 3 ("the same way").
- Flags for steps 2 and 3 are those CORE-HARDENING.md's Numbers section lists:
  `CL_FUZZ_CHECK BOTH REACH INVARIANT DUP TREE NOSIM`; step 2 (wide) adds
  `WIDE SIM UNDOSTEP REOPEN=25 UNDOALL=50`, plus `UNDOFIND` (only acts when UNDOALL
  would fail, to name the culprit steps).
- "Fixtures" start circuits (seed s starts from file s % 5): `tests/fixtures/core/drag-leaves-a-dot.cdl`,
  `tests/fixtures/core/straighten-redo.cdl`, `tests/fixtures/tidy-adder.cdl`,
  `tests/fixtures/tidy-inverters.cdl`, `res/samples/practice.cdl`. (The older runs in
  CORE-HARDENING.md used Lab5, Broadcast and Routing Backwards from
  `format/tests/fixtures`; those files are covered here by step 4.)
- Notes on the machine: the Mac reported battery power at the start (71%), then AC.
  The owner was sent one ntfy note about it.

Reproduce any seed (the command a failure would have used), from the repo root with
`mac/build/fuzz_edit` built by `mac/Tools/fuzz-check.sh`:

```
CL_FUZZ_CHECK=1 CL_FUZZ_BOTH=1 CL_FUZZ_REACH=1 CL_FUZZ_INVARIANT=1 CL_FUZZ_DUP=1 CL_FUZZ_TREE=1 CL_FUZZ_NOSIM=1 \
CL_FUZZ_WIDE=1 CL_FUZZ_SIM=1 CL_FUZZ_UNDOSTEP=1 CL_FUZZ_REOPEN=25 CL_FUZZ_UNDOALL=50 CL_FUZZ_UNDOFIND=1 \
CL_FUZZ_DUMP=/tmp/kept mac/build/fuzz_edit res/cl_gatedefs.xml <seed> 1 500 \
  tests/fixtures/core/drag-leaves-a-dot.cdl tests/fixtures/core/straighten-redo.cdl \
  tests/fixtures/tidy-adder.cdl tests/fixtures/tidy-inverters.cdl res/samples/practice.cdl
```
